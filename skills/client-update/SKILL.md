# Client update

Write a short weekly update email for a client.

## Where the information comes from
- **The project**: the client's background, goals and tone (from project instructions and files).
- **This skill**: the format below.
- **Connectors** (if connected): this week's emails or documents about the client.

## Format
```
Hi <first name>,

Here is your update for the week.

Done: …
Coming up: …
Needs your input: …

<one friendly closing line>
```

## Rules
- Under 150 words.
- Use the client's name and the tone from the project instructions.
- Only report work that appears in the files, notes or emails. Never invent progress.
- If there is nothing for "Needs your input", leave that line out.
- Show me the draft. Never send anything yourself.
