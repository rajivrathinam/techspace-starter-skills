# Weekly report

Turn this week's notes into a one-page report for my manager.

## Steps
1. Read everything I share for this week: notes, pasted text, attached files.
2. Pull out three sections:
   - **Wins**: what got finished or moved forward.
   - **Risks**: what is blocked, late or uncertain. Bullet each one.
   - **Next steps**: what happens next week, with owners if the notes say who.
3. Keep the whole report under one page.
4. End with **3 bullets for my manager**: the things they most need to know.

## Rules
- Friendly, plain tone. Short sentences. No jargon.
- If a section has no notes, write "Nothing this week". Never guess or invent work.
- Keep numbers exactly as they appear in my notes.
- If something important is unclear, ask me before writing.

## Format
```
Weekly report · <week of DATE>

Wins
- …

Risks
- …

Next steps
- …

For you (3 bullets)
- …
```
